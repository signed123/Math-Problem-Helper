# 实现结构与数据约定

## 分层

- `ui/`：Compose 页面、图片裁剪和离线数学排版。页面不直接构造模型 HTTP 请求。
- `AppViewModel`：页面状态、用户操作、进度及失败重试；SavedStateHandle 保留路由和文字草稿。
- `data/`：Room、事件记录、复习查询、DataStore、Keystore 和备份恢复。
- `ai/`：数学和语音接口；百炼实现与明确标识的演示实现。
- `media/`：私有图片、EXIF 方向修正、录音 WAV、语音播放及临时文件清理。

图片、密钥、录音不经过 WebView。数学内容使用打包在 APK 中的 KaTeX、Marked、DOMPurify；无 Javascript 原生桥，外部页面导航被阻止。

## 学习记录

`questions` 记录稳定题目 ID、创建时间和原题关联。`events` 记录每次题目版本、会话、学生消息、教师消息、作答、知识卡和掌握状态。事件具有题目 ID、会话 ID、类型、UTC 毫秒时间及类型化 JSON 内容。

查询需要的题目、活动、时间字段有 Room 索引；正文结构化字段由 Kotlin Serialization 解析。当前规模是个人题库，优先保持数据可追溯，不引入向量检索。

- 题目和知识卡修改追加版本，不覆盖旧历史。
- 首次学习、独立重做各有独立会话。重做页默认隐藏原会话；主动查看历史或方法卡会记录参考使用。
- 部分步骤正确、整题正确、无法确认分别处理。只有 `verdict=correct && complete=true` 才允许完成总结及生成复习计划。
- 提示使用依据当前会话内的提示按钮、参考查看及实际引导记录；后续重做不继承先前会话的提示使用标记。
- 题目条件改变后，旧完成状态和旧卡片不作为新条件下的当前成果，历史仍可回顾。

## 按时间复习

1. 用户选择本地日期，转换为 `[开始日零点, 结束日次日零点)`，同时保存时区与边界。
2. 根据区间内 `studentActivity=true` 的事件查询题目，包含早先建立、期间续聊的题。
3. 对每题读取 `at < endExclusive` 的所有记录，恢复当时的题干及状态，排除未来修改。
4. 全部记录分段总结；单条超长记录也会切段并保留原 ID，不用模型的最近若干条上下文冒充完整历史。
5. 逐题结果保存在 `review_items`，过滤不存在的引用 ID；缺少可核对依据时该题失败而非接受编造结论。
6. 完成项再分组归纳并保存到 `review_batches`。部分失败显示完成比例；重试跳过已完成项，进程退出后的 running 项可重试。

模型生成过程与历史保存分开。普通引导可使用上下文窗口；知识卡和历史复习要处理完整相关历史。

## 教学与校验

识题仅提取，不要求在识题结果中提供答案。候选题目有归一化区域，用户调整和确认后才建立题目。

引导请求有中文教学规则、三级提示及结构化输出。候选答复先做本地检查，再由独立模型请求检查是否代做或提前给答案；不通过时收窄重试，仍不通过返回固定引导问题。没有将关键词过滤或同模型复核宣称为绝对保证。

变式生成与验证使用两次独立请求上下文，最多尝试两次。内部参考过程留在内存，不保存到学生题干。未通过验证不创建练习题。

作答检查返回正确／需要修改／不确定及整题是否完成。图片不清和证据不足应返回不确定。后续仍需要真实题目集核查准确性。

## 数据库迁移

数据库版本 2，Room 导出 schema 保存在 `app/schemas/`。提供 1→2 迁移，为复习项增加非空 `error` 字段，保留已有题目及复习进度；不使用 destructive migration。

备份格式独立为版本 1，以逻辑记录导出，不直接复制仍在写入的 SQLite 文件。恢复合并经过校验的记录，不恢复服务密钥。

## 生命周期与失败处理

ViewModel 管理当前任务，取消会取消网络调用。用户离开前台会暂停朗读并停止麦克风采集，保留待转写录音草稿；录音最长两分钟。转写成功后写入可编辑草稿，不自动发送给辅导模型。

网络失败保留原消息和图片；重试同一待回复消息不会重复追加。复习进度逐题落库。语音失败不回滚已保存的文字答复。长时间原始录音不入学习库或备份。
